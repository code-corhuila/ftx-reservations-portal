# ftx-reservations-portal

> Reservations bounded context: web UI (remote)

Part of the **Futbolix** distributed system.

## Description

Frontend interface for the reservations bounded context.

The portal allows customers to:

- Select one of the initial four courts.
- Request a reservation without creating a customer account.
- Submit contact information.
- Select a date and a one-hour time slot.
- Consult a reservation using its confirmation code.

## Technologies

- React
- JavaScript
- Vite
